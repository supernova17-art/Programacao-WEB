## Descrição e decisões
- **EX01:** página pessoal de programador com títulos, parágrafos, imagem, links, lista e elementos semânticos. Não utiliza CSS nem JavaScript.
- **EX02:** perfil organizado com `header`, `nav`, `main`, `section`, `article`, `aside` e `footer`, com navegação interna por âncoras.
- **EX03:** página inicial de um jornal tecnológico com cinco notícias. Cada notícia apresenta categoria, autor, data, imagem e ligação para o artigo completo.
- **EX04:** formulário de contacto com campos identificados por `label`, tipos HTML5 adequados e validação nativa. Sem JavaScript.
- **EX05:** website para uma pequena empresa fictícia, com páginas de início, sobre, serviços e contactos, e navegação consistente. Sem CSS nem JavaScript.
