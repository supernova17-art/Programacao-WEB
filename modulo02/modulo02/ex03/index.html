Documentação de HTML e CSS

Notas simples para quem está a começar.

1. O que é HTML?

HTML é uma linguagem de marcação usada para estruturar o conteúdo de uma página web.

2. O que é CSS?

CSS é usado para controlar a apresentação visual, como cores, tipos de letra e espaçamentos.

Exemplo de código

body { font-family: Arial; }

Para aprender mais, consulta a documentação CSS.
